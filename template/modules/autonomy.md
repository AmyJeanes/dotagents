## Autonomous And Unattended Work

When the user explicitly hands off a task while stepping away, continue until it is genuinely complete or a hard blocker remains. Batch necessary clarifying questions before the run starts and restate the intended outcome, rather than interrupting it later.

Autonomy stays bounded: do not repeat the same failed approach for hours, and take a fallback the user supplied without asking again. Before finishing or risking loss of context, save findings and handoff state.

Autonomy is not permission to ship. Push and upstream-action rules still apply unless the user pre-authorized that action with the task; otherwise leave changes local for review.
